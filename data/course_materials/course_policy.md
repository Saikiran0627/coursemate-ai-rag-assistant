# Course Policy Summary

The final project requires a working LLM-powered application, a technical
paper, presentation slides, source code, and a demonstration. The application
must include a language-model component, a clear architecture, data
description, prompt design or model configuration, evaluation methodology,
multiple test cases, analysis of successful and failed responses, limitations,
and responsible AI or security discussion.

For the CourseMate project, the selected topic is Retrieval-Augmented
Generation. The assistant answers questions from course materials such as
lecture notes, slides, assignment descriptions, and policy documents. The
system must compare responses with RAG against responses without RAG.

Submissions should not include API keys, passwords, credentials, or sensitive
information. If a hosted model or service is used, credentials must be stored in
environment variables or local configuration files that are excluded from
version control.

The project paper should follow a research-paper structure: abstract,
introduction, background, system architecture, data and methodology,
implementation, evaluation and results, discussion, responsible AI and
security, conclusion, and references.
