# CourseMate Sample Course: Syllabus and Project Policy

Page 1

This sample document represents a course syllabus for an applied language model
class. It is designed for CourseMate stability testing and can be replaced with
real lecture materials. The course covers prompting, retrieval augmented
generation, embeddings, vector databases, tool use, evaluation, and responsible
AI.

Page 2

The final project requires a working LLM-powered application, source code,
documentation, an evaluation methodology, multiple test cases, a discussion of
successful and failed responses, limitations, and responsible AI considerations.
The project should demonstrate more than a single prompt to a model. Students
must explain why their system works, when it fails, and how they evaluated it.

Page 3

For the CourseMate project, the selected architecture is retrieval augmented
generation. CourseMate should answer from uploaded course materials, provide
source citations, and refuse to invent information when evidence is missing.
The system should compare answers with retrieval against answers without
retrieval using the same model where possible.
